# IMM v1.4.0 Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use combo:subagent-driven-development (recommended) or combo:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle and restructure every page of IMM so the first viewport answers one question in plain Indonesian, without changing data, logic, navigation, or the native shell.

**Architecture:** A shared presentation layer is added beside the existing code: pure helpers in `www/ui-core.js` (unit-tested), shared components in `www/ui.js`, and the new token/style layer in `www/ui.css` loaded after the inline styles. Page functions in `www/index.html` and `www/inbound.js` are rewritten to compose those components; existing selectors used by tests stay.

**Tech Stack:** Vanilla JS/CSS, `node --test`, Playwright (local), Impeccable detector.

**Spec:** `docs/superpowers/specs/2026-10-04-redesign-design.md` · product truth: `PRODUCT.md`

## Global Constraints

- No change under `android/`, `capacitor.config.json`, or `package.json` dependencies (must ship as a live update on native base 1.3.0).
- No change to data loading, calculations, navigation keys, the Inbound lock, or the forced-update gate.
- Existing e2e selectors keep working: `.lpn`, `.put-sum [data-putf]`, `#putLoc`, `.prod-team`, `.prod-op`, `.rank`, `.tto-row`, `.mpp-p`, `[data-inb]`, `[data-seg]`, `.stage`, `#updGate`, `#roleGate`, `.ins-wrap`.
- Visible text ≥ 12 px (SVG chart text excluded). Text tokens ≥ 4.5:1 on their surfaces in light and dark.
- `button`, `select`, `input`, `[role=tab]`: height ≥ 44 px; icon-only buttons ≥ 40×40 px.
- Motion 150–250 ms for state changes; nothing animates under "Kurangi animasi" or `prefers-reduced-motion`.
- Fonts stay Plus Jakarta Sans + JetBrains Mono. Binding colors: Storing green, Outbound orange, Customer blue; BU colors unchanged.
- UI copy Indonesian; no customer personal names; no invented numbers — every figure comes from the model already in memory.
- Commits: identity `Claude <noreply@anthropic.com>`, "Untuk pengguna:" / "Untuk developer:" sections; push to `feat/redesign` only; `main` only on "gaspol".

## Review Focus

1. A day/period with no data at all → the lead card shows "Belum ada jadwal …" with 0 and no comparison line, never `NaN`, `Infinity`, or an empty dark box. (Task 2 e2e.)
2. Very long values (LC with 20+ depts, 7-digit CBM, long site names) → wrap or truncate inside the card, no horizontal scroll at 360 px. (Task 7 sweep with a long-value fixture.)
3. Filter set to a range ("30 hari terakhir") → week strip shows no selected day and the headline names the range, not "hari ini". (Task 2 e2e.)
4. One sheet failing (kontainer or inbound) → that page's lead card is replaced by the existing error card; other pages keep their lead cards. (Task 4 and 5 e2e.)
5. Dark mode → every new surface keeps ≥ 4.5:1 text contrast; the dark lead card stays distinguishable from the dark page ground. (Task 1 unit + Task 7 sweep.)

### Task 1: Foundations — helpers, tokens, shared components

**Files:** Create `www/ui-core.js`, `www/ui.js`, `www/ui.css`, `tests/ui.test.mjs`, `test/e2e-design.js`. Modify `www/index.html` (tags only), `scripts/check.mjs`, `build-preview.py`.

**Interfaces — Produces:**
- `IMMUi.contrast(hexA: string, hexB: string): number` — WCAG ratio.
- `IMMUi.weekDays(today: 'YYYY-MM-DD'): string[]` — 7 ISO dates, `today-1 … today+5`.
- `IMMUi.splitZeros<T>(items: T[], value: (x:T)=>number): {shown: T[], zeros: T[]}` — order preserved.
- `IMMUi.deltaInfo(cur: number, base: number): null | {dir: 'up'|'down'|'same', pct: number}` — `null` when `base <= 0` or either is not finite; `same` when |pct| < 1.
- `IMMUi.GLOSSARY: Record<string,{t:string,d:string}>` with keys `cbm, teus, lc, lpn, dept, bu, yard, dooring, leadtime, p90, campur, lppbdo, tto`.
- In `ui.js`: `lead({tone, kicker, headline, value, unit, stats:[{l,v,u?}], delta, body?}) : string` (root `.lead[data-tone]`, headline in `.lead-h`, number in `.lead-v`), `weekStrip(days:[{d,v}], selected, max)` (buttons `[data-day]`, today has `.today`, selected `aria-pressed="true"`), `attention(items:[{n,label,tone,attr?}])` (root `.attn`; empty list renders `.attn.calm`), `zeroLine(text)` (`.zero-line`), `secHead({icon,title,sub,hint?,gloss?})` (keeps `.ch` + `h2`), `glossBtn(keys:string[])` (`[data-gloss]`), `openGloss(keys)`.
- Click handling for `[data-day]` and `[data-gloss]` in the existing document click handler.
